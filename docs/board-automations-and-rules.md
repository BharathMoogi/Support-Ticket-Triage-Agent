# Board Automations & Rules

Automations help streamline repetitive tasks without writing code.

## Types of Automations
- **Card Move Triggers**: Automatically assign a reviewer when a card moves to 'In Review'.
- **Due Date Reminders**: Send a Slack alert or email 24 hours before a card due date.
- **Checklist Automation**: Auto-create sub-tasks when a card is added to a specific column.

## Monthly Automation Limits
- **Free**: 100 runs / month
- **Pro**: 1,000 runs per user / month (pooled across workspace)
- **Team**: 10,000 runs per user / month

## Checking Automation Logs
Go to **Board Menu > Automations > Run History** to inspect triggers, check execution timestamps, and view failure error messages.
