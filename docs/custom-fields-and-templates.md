# Custom Fields & Board Templates

## Custom Fields
Custom fields allow tracking structured data such as Priority, Budget, Story Points, or Dropdown Categories.
- **Free Tier**: 1 custom field per board.
- **Pro & Team**: Unlimited custom fields across text, dropdown, number, currency, date, and formula types.
- To add a field: Click **Add Field** at the top of any card modal or board header table.

## Board Templates
- Save any existing board as a reusable template via **Board Menu (...) > Save as Template**.
- Pro and Team workspaces can publish shared **Workspace Templates** visible in the template gallery for all team members.
