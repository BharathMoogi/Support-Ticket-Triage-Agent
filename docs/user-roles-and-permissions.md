# User Roles & Workspace Permissions

FlowBoard supports 4 distinct user roles:

## 1. Workspace Owner
- Complete control over billing, subscription, integrations, security, and workspace deletion.
- Can promote/demote Admins and transfer ownership.

## 2. Admin
- Can create, edit, and delete any board in the workspace.
- Can invite or remove Members and Guests.
- Cannot view billing details or delete the workspace.

## 3. Member
- Can create boards, create/edit cards, add comments, and invite single-board Guests (if permitted by Admin settings).
- Billed as an active seat on paid plans.

## 4. Guest / Viewer
- Restricted to explicitly shared boards only.
- Cannot create new boards or view other workspace members.
- Free unlimited read-only viewers on Pro and Team plans.
