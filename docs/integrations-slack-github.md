# Integrations: Slack, GitHub & Webhooks

## Slack Integration
- **Connect**: Go to **Workspace Settings > Integrations > Slack** and click **Authorize**.
- **Features**: Post board activity to designated Slack channels, create cards directly via \/flowboard create [title]\, and receive interactive notification buttons.

## GitHub Integration
- Link commits and Pull Requests to cards by including the card reference ID in commit messages (e.g. \Fixes FB-104\).
- Automatically move cards to 'Done' when associated Pull Requests are merged into the default branch.

## Custom Webhooks
- Pro and Team workspaces can create outbound webhooks under **Settings > Developers > Webhooks** to notify external endpoints on card creation, updates, and comments.
